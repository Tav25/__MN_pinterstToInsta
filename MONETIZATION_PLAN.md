## Этап 2. SaaS-версия (недели 5–10)

Цель — продукт, который можно продавать.

### Функциональность
- [ ] Серверный извлекатель: POST /api/extract { pinUrl } → { videoUrl, thumb, meta }
- [ ] Веб-интерфейс: вставил ссылку → скачал MP4
- [ ] Пакетная обработка (список ссылок → ZIP)
- [ ] Лимиты по IP/user_id (free: 5/день)

### Инфраструктура (всё дружит с Lovable)
```
Лендинг + кабинет (Lovable)
        │
   Supabase ── Auth, БД (users, downloads), Edge Functions
        │
   Worker (Cloudflare/Deno) ── extraction API
        │
   Rate limiter (Upstash Redis)
```

## Этап 3. Приём платежей из Беларуси на весь мир

### Вариант A (быстрый старт): Lemon Squeezy / Paddle
- [ ] Зарегистрировать аккаунт как физлицо РБ
- [ ] **Проверить доступность выплат** (PayPal/Wise/банковский перевод) ДО запуска

- [ ] Webhook → Supabase → флаг pro у пользователя
- Комиссия ~5%, налоги платит сервис за вас

### Вариант B (параллельно): крипта
- CryptoCloud или CryptoBot: USDT/BTC, без юрлица
- Для аудитории тулз конверсия приемлемая, запуск за день

### Вариант C (при стабильных $500+/мес): юрлицо
- ИП/ООО в Армении / Грузии / Кыргызстане (удалённо, от ~$200)
- Полноценный Stripe + банковский счёт + легальный доход

Это решает бизнес-задачу SMM-специалистов, а не просто «скачать файл».
Подписка $10–30/мес.
